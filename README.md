# Мессенджер

Учебный проект мессенджера: TypeScript + Vite + Handlebars + PostCSS.
Спринт 2: компонентный подход на базе `Block`, валидация форм, архитектура MVC.

## Команды

- `npm install` — установка зависимостей
- `npm run dev` — dev-сервер на http://localhost:3000
- `npm run build` — проверка типов и сборка в `dist`
- `npm run start` — сборка и запуск `vite preview` на 3000 порту

## Страницы

| Путь | Страница |
|------|----------|
| `/` | Навигация по всем страницам |
| `/login` | Авторизация |
| `/sign-up` | Регистрация |
| `/messenger` | Список чатов и переписка |
| `/settings` | Настройки профиля |
| `/404` | Не найдено |
| `/500` | Ошибка сервера |

Страницы генерируются на клиенте. Любой путь отдаёт `index.html`, а нужную страницу выбирает `router.ts`, неизвестный путь показывает 404.

## Архитектура (MVC)

```
src/
  core/          Block — базовый класс компонентов, registerComponent — регистрация в Handlebars
  components/    View: Button, Input, Field, Avatar, ChatItem, Message
  pages/         View: страницы, тоже наследники Block
  controllers/   Controller: AuthController, UserController, ChatController
  models/        Model: типы и данные пользователя и чатов (пока моки)
  utils/         validation — правила валидации, form — общий обработчик submit,
                 registerComponents — регистрация всех компонентов
  styles/        переменные и базовые стили
  router.ts      pathname → класс страницы
  main.ts        точка входа
```

Каждый компонент и страница лежат в своей папке в одном формате: класс `.ts`, шаблон `.hbs`, стили `.pcss` и `index.ts` с экспортом.

### Компоненты

Компонент наследуется от `Block` и регистрируется как Handlebars-хелпер. В шаблоне он вызывается так: `{{{ Button text="Войти" type="submit" }}}`. Внутри `{{#each}}` можно передать текущий элемент целиком: `{{{ ChatItem this }}}`.

Жизненный цикл: `componentDidMount`, `componentWillUnmount`. Вызов `setProps` обновляет props и перерисовывает компонент. События задаются в поле `events` и навешиваются на корневой элемент компонента.

### Формы и валидация

- Правила на регулярных выражениях описаны один раз в `utils/validation.ts` и используются во всех формах.
- Поле проверяется на `blur`, вся форма — на `submit`.
- При отправке страница не перезагружается (`preventDefault`), а в консоль выводится объект со всеми полями формы.
- Валидация подключена к формам авторизации, регистрации и настроек пользователя.
